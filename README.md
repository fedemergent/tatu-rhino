# TATU · Tutorial Recording for Rhino

Programa gratuito para **grabar video tutoriales de Rhino** con todo incluido: cursor y clics resaltados, tarjetas con el nombre de cada comando, subtítulos, cámara web, voz con IA, doblaje al inglés, resumen vertical para Reels y edición básica antes de exportar.

> Versión **preliminar** (1.1.4). Hecho por [fedemergent](https://github.com/fedemergent) · [F3DE Design](https://fedemergent.github.io/f3de-design/)

## Descargar
Descarga el instalador desde la web: **https://fedemergent.github.io/f3de-design/#plugins**
(o directamente desde la sección *Releases* de este repositorio).

## Requisitos
- Windows 10 u 11
- Rhino 8 (para la barra y el registro de comandos dentro de Rhino)

## Instalar
1. Cierra Rhino.
2. Ejecuta `TATU_Setup.exe`.
3. Si Windows muestra «Windows protegió su PC» (el instalador todavía no está firmado), elige **Más información → Ejecutar de todos modos**.
4. Abre Rhino: aparece la barra de TATU. Si no, escribe el comando `TATU`.
